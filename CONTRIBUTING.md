# Contributing to Tucunar Labs

Thanks for taking the time to contribute.

## Before you start

- Each repository has its own license. Read its `LICENSE`, `NOTICE` and
  `TRADEMARK.md` before contributing.
- Security issues go to **hola@tucunar.com**, not to public issues.

## Developer Certificate of Origin

We use the Developer Certificate of Origin (DCO) 1.1. By submitting a
contribution you certify that you have the right to submit it under the
repository's license and that you agree to the DCO:

<https://developercertificate.org/>

Sign off every commit:

```bash
git commit -s -m "your message"
```

The sign-off adds a `Signed-off-by: Your Name <you@example.com>` trailer.
Pull requests without sign-offs may be asked to amend the commits.

## Pull requests

- Keep changes focused and explain the problem they solve.
- Run the checks documented in the repository's README.
- Do not include real credentials, Firebase configuration, keystores, `.env`
  files, build artifacts or personal data.
- Be respectful. See `CODE_OF_CONDUCT.md`.
