# Security Policy

## Reporting a vulnerability

Please report security issues privately to **hola@tucunar.com**. Do not open a
public GitHub issue for a vulnerability.

Include enough detail to reproduce the issue, the affected repository and
version, and any relevant logs with personal data removed. We will acknowledge
the report and coordinate disclosure.

## Scope

Each repository documents its own scope. The Firebase projects and hosted
services used by official Tucunar Labs builds are operated by Tucunar SpA;
self-hosted deployments are the responsibility of their owner.

## Supported versions

Security fixes are applied to the latest release of each product. Older
releases may not receive backports.
